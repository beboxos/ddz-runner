# DDZ Runner

Endless runner 3D (Three.js) dans un data center : change de voie, saute les baies, monte sur les rampes,
ramasse les bonus, évite le Chef Admin Réseau et les flics, séduis… et dépense ta cagnotte dans la boutique
(bonus, skins, décors : salle serveurs, Love Room, plage, salle de sport).

**Jouer :** https://beboxos.github.io/ddz-runner/

Sur téléphone, le jeu s'installe comme une appli :
- **iPhone (Safari) :** bouton Partager → « Sur l'écran d'accueil »
- **Android (Chrome) :** menu ⋮ → « Ajouter à l'écran d'accueil »

Contrôles : glisser ← → pour changer de voie, glisser ↑ ou taper pour sauter, glisser ↓ pour retomber.
Au clavier : flèches ou Q/D, Espace pour sauter, 1 à 4 pour les bonus d'inventaire.

La progression (record, cagnotte, achats) est sauvegardée sur l'appareil. Le jeu fonctionne ensuite hors ligne.
